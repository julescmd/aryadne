# Raccourcis

Cette liste est tirée du code. `Ctrl` devient `Cmd` sous macOS. `Maj` est la touche Shift.

La barre du bas de l'application rappelle les raccourcis de l'outil en cours. C'est l'aide la plus à jour.

Deux familles :

- les **raccourcis globaux**, modifiables dans `Settings › Shortcuts` ;
- les **raccourcis de chaque éditeur**, fixes. Ils n'agissent que quand la souris est sur l'éditeur.

## Conflits à connaître

- `Ctrl+L` : assistant (global), choisir la ligne (code), lier un clip (montage), pièces liées (3D). L'éditeur sous la souris l'emporte quand il gère la touche.
- `Ctrl+G` : cerveau (global), aller à la ligne (texte), grouper (retouche, vectoriel, nœuds).
- `Ctrl+J` : note du jour (global), joindre (3D), dupliquer le calque (retouche), cadre (nœuds), joindre des tracés (vectoriel).
- `Ctrl+D` : dupliquer presque partout, mais désélectionner en retouche et fondu enchaîné au montage.
- `Ctrl+E` : lecture d'une note, fusionner avec le dessous (retouche), menu des coutures (3D).

Les raccourcis globaux peuvent être changés ou retirés dans `Settings › Shortcuts` pour lever un conflit.
