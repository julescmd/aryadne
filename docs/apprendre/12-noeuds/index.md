## Ce que tu vas apprendre

Un graphe de nodes est une suite de petites boîtes reliées par des fils. Chaque boîte fait une seule chose. Les données vont de gauche à droite, jusqu'à un node de sortie.

Aryadne se sert du même éditeur pour trois genres de fichiers.

| Fichier | Sert à | Parcours |
|---|---|---|
| `.arymat` | Les nodes d'un calque de matériau | [Matériaux : l'Atelier](../11-materiaux-atelier/index.md) |
| `.arycomp` | Retoucher une image | [Compositing](../13-compositing/index.md) |
| `.arygeo` | Des points, une simulation | [Simulation](../14-simulation/index.md) |

Ce que tu apprends ici vaut pour les trois.
