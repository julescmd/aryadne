# Court métrage : Le phare

Un gardien de phare trouve une lettre dans une bouteille. Elle vient de lui, plus jeune.

## Personnages

Le gardien s'appelle Anselme. Il vit seul depuis trente ans.

## Décors

Tout se passe sur une île. Le phare, la grève, la cuisine.

- [ ] Écrire la fiche d'Anselme
