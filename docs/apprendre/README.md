# Apprendre Aryadne

Un programme complet, pas à pas, pour apprendre tout le logiciel. Ce n'est pas une documentation. Tu lis une leçon, tu fais les gestes dans Aryadne, et tu vois le résultat.

## Comment ça marche

- **File › Help › Learn** ouvre le panneau des leçons, à côté de ton travail. L'icône de toque, en bas du rail, fait de même.
- Chaque leçon dure 10 à 20 minutes. Elle commence par ce que tu vas réussir à faire.
- Le bouton **Try it yourself** crée un point de départ dans un dossier `Apprendre/` de ton coffre. C'est une copie : tu ne peux rien casser.
- Les étapes se cochent toutes seules quand Aryadne voit que le geste est fait. Les autres se cochent à la main.
- Chaque leçon a un ou plusieurs quiz, et un défi libre à la fin.
- Ta progression est gardée dans ton coffre. Tu reprends où tu t'es arrêté.

Les libellés de l'interface sont écrits en **gras**, en anglais, tels qu'ils s'affichent.

Les leçons disent quoi faire. Pour savoir ce que fait un réglage précis, ouvre la documentation : **File › Help › Documentation**, ou le [guide d'utilisation](../utilisateur/prise-en-main.md).

## Ce qu'il te faut

- Aryadne, et un coffre. La [première leçon](01-demarrer/01-installer-et-lancer.md) s'en occupe.
- Pour la vidéo, le son et les exports animés : ffmpeg. Aryadne propose de l'installer, sans droits administrateur.
- Pour les scripts : Python 3.
- Pour l'assistant : un modèle d'IA, local ou en ligne. C'est facultatif.
- Une tablette graphique aide pour le dessin et la sculpture. Une souris suffit pour tout le reste.
