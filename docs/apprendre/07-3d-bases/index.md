## Ce que tu vas apprendre

Une scène 3D est un fichier `.aryscene`. Elle s'ouvre dans l'outil **Scene** de l'étape **3D**. Elle réunit des objets : modèles, lumières, caméras.

Ce parcours te rend à l'aise dans la vue. Tu sauras te déplacer, placer des objets, les éclairer, les cadrer et les faire bouger.

Les gestes ressemblent à ceux de Blender : molette enfoncée pour tourner, G, R, S pour transformer.
