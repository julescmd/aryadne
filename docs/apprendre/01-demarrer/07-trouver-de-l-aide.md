## Ce que tu vas réussir à faire

Tu vas apprendre à te débloquer seul. Aryadne a quatre aides : la barre du bas, le mode Apprendre, la documentation et l'écran d'accueil.

```essayer
nouveau: md
nom: mes-questions
```

```etape
Clique **Essaie par toi-même**. Tu noteras dans ce fichier ce que tu veux retrouver plus tard.
verifier: fichier.ouvert = md
```

## Quelle aide pour quelle question

| Ta question | Où regarder |
|---|---|
| Quelle touche fait quoi ici ? | La barre du bas |
| Comment apprendre un outil pas à pas ? | Le mode Apprendre |
| Que fait ce réglage précis ? | La documentation |
| Par où commencer aujourd'hui ? | L'écran d'accueil |

## La barre du bas

Au centre de la barre du bas, Aryadne écrit les raccourcis de l'endroit que tu survoles. Elle en montre trois. Le survol de ce texte les montre tous.

```etape
Pose la souris sur ta note, puis sur le texte au centre de la barre du bas. Lis la liste complète.
```

Presque chaque bouton est une icône. Laisse la souris dessus un instant : son nom s'affiche.

## Le mode Apprendre

Tu y es. Ce programme compte seize parcours, du premier lancement aux projets complets.

- Chaque leçon commence par ce que tu vas réussir à faire.
- **Essaie par toi-même** ouvre un point de départ dans le dossier `Apprendre/` de ton coffre. C'est toujours une copie.
- Une étape se coche seule quand Aryadne peut le vérifier. Sinon, coche-la toi-même.
- Une leçon est terminée quand toutes ses étapes sont cochées et tous ses quiz réussis.

Ta progression est gardée dans ton coffre. Tu peux arrêter et reprendre quand tu veux.

```astuce
Tu n'es pas obligé de suivre l'ordre. Le [sommaire](../README.md) propose un chemin rapide par envie : matériaux, simulation, montage.
```

## La documentation

La documentation est livrée avec Aryadne. Elle s'ouvre comme une note, sans internet.

```etape
Ouvre **File › Help › Documentation**. Le sommaire de la documentation s'ouvre en lecture.
```

Elle a deux parties : le guide d'utilisation, un fichier par outil, et une partie technique pour ceux qui lisent le code.

```etape
Dans le sommaire, clique le lien de la page des raccourcis. Parcours la liste.
```

```astuce
La palette ouvre aussi la documentation : `Ctrl+K`, puis tape `doc`.
```

Différence avec ce programme : la documentation décrit chaque bouton. Les leçons, elles, te font faire les choses dans l'ordre.

## Le menu Help

**File › Help** réunit le reste.

| Commande | Effet |
|---|---|
| **Home** | L'écran d'accueil |
| **Documentation** | La documentation |
| **Keyboard shortcuts** | La liste des raccourcis, dans les réglages |
| **Time spent per project** | Le temps actif passé sur chaque fichier |
| **Check for updates** | Cherche une nouvelle version |
| **Example Python script (API)** | Un script d'exemple, prêt à lancer |
| **Measure the graphics card** | Un banc d'essai de ta carte graphique |

## L'écran d'accueil

```etape
Ouvre **File › Help › Home**.
```

L'écran d'accueil montre :

- **Pick up where you left off** : le coffre et les onglets à rouvrir ;
- **Start** : les fichiers les plus courants à créer ;
- **Recent** : tes derniers fichiers ;
- **Ask the Assistant** : une question directe à l'assistant ;
- **Useful shortcuts**.

Chaque étape vide affiche aussi sa propre page d'accueil, avec un bouton pour créer le bon fichier.

## L'assistant

`Ctrl+L` ouvre l'assistant à côté de ton travail. Il voit le fichier ouvert et peut expliquer ou proposer un changement. Il demande un modèle d'IA branché : ce n'est pas obligatoire, tout le reste marche sans. Tu le découvriras dans le parcours [Vidéo, son et code](../06-video-son-code/index.md).

## Mises à jour

Le numéro de version est en bas à droite. Un clic dessus ouvre la fenêtre des mises à jour.

```etape
Écris dans ta note une question que tu te poses sur Aryadne. Cherche la réponse dans la documentation.
```

```quiz
Tu cherches le raccourci d'un outil de dessin. Quel est le chemin le plus court ?
- [x] Survoler l'éditeur et lire la barre du bas.
- [ ] Rouvrir l'écran d'accueil.
- [ ] Redémarrer Aryadne.
explication: La barre du bas suit l'outil en cours. C'est l'aide la plus à jour.
```

```quiz
Où se trouve la commande Documentation ?
- [ ] Edit › View
- [x] File › Help
- [ ] Dans le rail
explication: Le menu Help est un sous-menu de File. La palette l'ouvre aussi.
```

```defi
Trouve dans la documentation la liste des formats de fichiers 3D qu'Aryadne sait lire.
indice: Page « Coffre et fichiers », section « Formats lus ».
```

## Récapitulatif

- La barre du bas donne les touches de l'endroit survolé.
- **File › Help › Documentation** ouvre la documentation complète, hors ligne.
- Le mode Apprendre te fait pratiquer, et garde ta progression dans le coffre.
