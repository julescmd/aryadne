## Ce que tu vas apprendre

Deux outils se complètent pour donner une forme à un objet.

- Le **mode édition** change le maillage lui-même, sommet par sommet.
- La **pile de modificateurs** transforme le maillage sans le toucher. Tout reste réversible.

En fin de parcours, la **retopologie** refait un maillage propre à partir d'un modèle trop dense.
