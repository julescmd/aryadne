## Ce que tu vas réussir à faire

Tu vas dessiner une petite scène en quatre cases : quelqu'un entre, voit quelque chose, réagit, sort. Des bonshommes en bâtons suffisent. Un storyboard sert à raconter, pas à faire joli.

```essayer
nouveau: arystory
nom: premiere-scene
```

```etape
Clique **Try it yourself**. Un storyboard s'ouvre dans l'étape Video, outil **Storyboard**. Il arrive avec trois cases vides.
verifier: onglet = video
```

## L'écran

| Zone | Contenu |
|---|---|
| Au centre | La case en cours, à dessiner |
| À droite | Les informations de la case |
| En bas | La bande des cases |

Chaque case est une image PNG. Aryadne les range dans un dossier « nom - cases », à côté du fichier.

## Les outils de dessin

| Outil | Touche | Usage |
|---|---|---|
| **Pencil** | `P` | Le crayon d'esquisse |
| **Ink** | `I` | Le trait net |
| **Tone, light gray** | `T` | Un gris léger, pour les ombres |
| **Fill** | `F` | Entoure une zone pour la remplir |
| **Eraser** | `E` | La gomme |
| Le pot de peinture | `G` | Remplit une zone fermée |

```etape
Appuie sur `P`. Esquisse un décor simple : une ligne de sol, une porte.
```

```etape
Appuie sur `I`. Repasse au trait net sur ce que tu veux garder. Dessine un personnage qui entre.
```

```etape
Appuie sur `T`. Pose un gris léger sous le personnage : son ombre.
```

```raccourci
`[` et `]` changent la taille du trait. `Ctrl+Z` annule, `Ctrl+Y` rétablit.
```

```astuce
Le ton gris donne la lecture en trois secondes : où est la lumière, où regarder. Deux valeurs et le blanc du papier suffisent.
```

## Une deuxième case

```etape
Appuie sur `→` pour passer à la deuxième case. Elle est vide.
```

```etape
Appuie sur `O` pour la pelure d'oignon. La case d'avant apparaît en transparence. Dessine le personnage qui s'arrête et regarde.
```

La pelure d'oignon t'aide à garder le décor et les proportions d'une case à l'autre.

## Partir de la case d'avant

Souvent, la case suivante reprend le même cadre. Duplique au lieu de redessiner.

```etape
Appuie sur `Ctrl+D` : **Duplicate panel**. Tu as une copie de la deuxième case.
```

```etape
Sur la copie, gomme le visage avec `E` et redessine une expression de surprise.
```

Il te reste une case vide, la dernière des trois de départ. Elle ne sert plus : ta copie a pris sa place dans l'histoire.

```etape
Va sur la dernière case avec `→`. Dessine la porte vide : le personnage est sorti.
```

```etape
Appuie sur `N` : **New panel after**. Une cinquième case s'ajoute. Supprime-la avec le bouton de la corbeille : tu sais maintenant ajouter et retirer une case.
```

## Se déplacer dans les cases

| Geste | Raccourci |
|---|---|
| Case précédente, suivante | `←` `→` |
| **Move earlier**, **Move later** : déplacer la case | `Alt+←`, `Alt+→` |
| **New panel after** | `N` |
| **Duplicate panel** | `Ctrl+D` |
| **Delete panel** | Le bouton de la corbeille |

```etape
Reviens à la première case avec `←`. Parcours tes quatre cases avec `→`.
```

```etape
Va sur la troisième case. Appuie sur `Alt+←` : elle passe en deuxième. Remets-la avec `Alt+→`.
```

```attention
**Delete panel** retire la case du storyboard. Son dessin reste sur le disque, dans le dossier des cases.
```

## Enregistrer

```etape
Enregistre avec `Ctrl+S`.
```

```quiz
Que fait la touche O dans le storyboard ?
- [ ] Elle ouvre un fichier.
- [x] Elle montre la case précédente en transparence.
- [ ] Elle trace une ellipse.
explication: C'est la pelure d'oignon. Elle garde le décor et les proportions sous les yeux.
```

```quiz
Quelle touche ajoute une case après la case en cours ?
- [x] `N`
- [ ] `Ctrl+N`
- [ ] `+`
explication: N ajoute une case. Ctrl+N, lui, crée une note.
```

```defi
Raconte en six cases : un chat voit un verre au bord d'une table, hésite, puis le pousse.
indice: Duplique les cases où le cadre ne change pas avec `Ctrl+D`. Ne redessine que ce qui bouge.
```

## Récapitulatif

- `P` esquisse, `I` encre, `T` pose un ton gris, `E` gomme.
- `N` ajoute une case, `Ctrl+D` la duplique, `Alt+←` et `Alt+→` la déplacent.
- `O` montre la case d'avant en transparence.
